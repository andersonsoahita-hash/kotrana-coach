# Kotrana Coach · by Stephen — fichiers du site

Mets **tous ces fichiers** à la racine de ton dépôt GitHub (ex. `kotrana-coach`), puis active GitHub Pages
(Settings → Pages → Deploy from a branch → main → / (root)).

- `index.html` : l'app (adhérents et coach)
- `admin.html` : TA page d'administration (protégée par ta clé admin)
- `config.js` : l'adresse de ton serveur Google
- `sw.js` : permet d'ouvrir l'app avec une mauvaise connexion
- `entree.js`, `version.json`, `manifest.json`, `icon-*.png` : accueil animé, mises à jour, icône écran d'accueil

Liens une fois en ligne :
- App : https://TON-COMPTE.github.io/kotrana-coach/
- Admin : https://TON-COMPTE.github.io/kotrana-coach/admin.html
- Inscription d'un adhérent : le lien affiché dans l'onglet « Coachs » de l'admin (il contient le code du coach).

Quand tu modifies le serveur (Code.gs) : Apps Script → Déployer → Gérer les déploiements → ✏️ → Nouvelle version.
